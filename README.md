# Digital Store Management System

A simple digital store management system developed for a university Database course. Built with Python and connected to an SQL database, it manages buyer information and product quantities through a minimal graphical interface, focusing on core database concepts.

## Features
- Store and manage buyer information
- Track product quantities
- Persistent data with SQL
- Simple GUI for interaction

## Technologies
- Python
- SQL (SQLite / PostgreSQL)
- Simple GUI (Tkinter)

## How to Run
1. Install Python
2. Set up the SQL database and tables
3. Update database connection settings in the code
4. Run the main Python file
